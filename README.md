# Win32 俄罗斯方块游戏 (Direct2D版本)

这是一个使用C++、Win32 API和Direct2D图形API开发的现代化俄罗斯方块游戏。

## 功能特性

### 🎮 游戏功能
- 经典的俄罗斯方块游戏玩法
- 7种不同形状的方块（I、O、T、S、Z、J、L）
- 方块旋转和移动
- 行消除和计分系统
- 等级系统（随着消除行数增加而提升）
- 下一个方块预览
- 暂停功能
- 游戏结束后重新开始

### 🎨 视觉效果 (Direct2D增强)
- **硬件加速渲染**：使用Direct2D进行高性能图形渲染
- **渐变背景**：游戏板和UI面板使用美观的渐变效果
- **方块阴影**：实时显示方块落地位置的半透明预览
- **高光效果**：方块具有3D视觉效果和高光边框
- **圆角界面**：现代化的圆角矩形UI设计
- **平滑文本**：使用DirectWrite进行高质量文本渲染
- **透明效果**：UI元素支持透明度和混合效果
- **网格线**：游戏板显示精细的网格辅助线

## 编译要求

### Windows + MinGW
```bash
g++ -std=c++11 -Wall -Wextra -O2 -o tetris.exe main.cpp -ld2d1 -ldwrite -lgdi32 -luser32 -lkernel32
```

**注意**：需要Windows 7或更高版本，以及支持Direct2D的系统。

### Windows + Visual Studio
在Visual Studio中创建新的Win32控制台项目，将main.cpp添加到项目中，然后编译。

### 使用Makefile
如果安装了MinGW和Make：
```bash
make
```

## 游戏控制

- **←/→ 方向键**: 左右移动方块
- **↓ 方向键**: 加速方块下降
- **↑ 方向键**: 旋转方块
- **空格键**: 瞬间下降方块到底部
- **P键**: 暂停/继续游戏
- **R键**: 游戏结束后重新开始

## 计分规则

- 每消除一行得到 100 × 当前等级 分
- 使用加速下降每格得2分
- 每消除10行等级提升1级
- 等级越高，方块下降速度越快

## 技术实现

### 🏗️ 核心技术
- **Win32 API**：窗口创建和消息处理
- **Direct2D**：硬件加速的2D图形渲染
- **DirectWrite**：高质量文本渲染和字体管理
- **COM接口**：Direct2D和DirectWrite的资源管理

### 🎯 图形渲染特性
- **渲染目标管理**：自动处理设备丢失和重建
- **资源优化**：智能的画刷和渲染资源缓存
- **渐变效果**：线性渐变背景和UI元素
- **透明混合**：Alpha通道支持和透明度控制
- **抗锯齿**：平滑的线条和文本渲染

### 🔧 游戏架构
- 基于时间的游戏循环
- 面向对象的游戏逻辑设计
- 精确的碰撞检测算法
- 高效的行消除算法
- 实时阴影预览系统
