# Win32 俄罗斯方块游戏

这是一个使用C++和Win32 API开发的经典俄罗斯方块游戏。

## 功能特性

- 经典的俄罗斯方块游戏玩法
- 7种不同形状的方块（I、O、T、S、Z、J、L）
- 方块旋转和移动
- 行消除和计分系统
- 等级系统（随着消除行数增加而提升）
- 下一个方块预览
- 暂停功能
- 游戏结束后重新开始

## 编译要求

### Windows + MinGW
```bash
g++ -std=c++11 -Wall -Wextra -O2 -o tetris.exe main.cpp -lgdi32 -luser32 -lkernel32
```

### Windows + Visual Studio
在Visual Studio中创建新的Win32控制台项目，将main.cpp添加到项目中，然后编译。

### 使用Makefile
如果安装了MinGW和Make：
```bash
make
```

## 游戏控制

- **←/→ 方向键**: 左右移动方块
- **↓ 方向键**: 加速方块下降
- **↑ 方向键**: 旋转方块
- **空格键**: 瞬间下降方块到底部
- **P键**: 暂停/继续游戏
- **R键**: 游戏结束后重新开始

## 计分规则

- 每消除一行得到 100 × 当前等级 分
- 使用加速下降每格得2分
- 每消除10行等级提升1级
- 等级越高，方块下降速度越快

## 游戏截图说明

游戏窗口包含：
- 左侧：主游戏区域（10×20格子）
- 右侧上方：下一个方块预览
- 右侧中间：分数、等级、已消除行数显示
- 右侧下方：控制说明

## 技术实现

- 使用Win32 API创建窗口和处理消息
- GDI绘图API进行游戏渲染
- 基于时间的游戏循环
- 面向对象的游戏逻辑设计
- 碰撞检测和行消除算法

## 文件结构

- `main.cpp`: 主程序文件，包含所有游戏逻辑和Win32窗口代码
- `Makefile`: 编译脚本
- `README.md`: 说明文档

## 注意事项

1. 此程序专为Windows平台设计，使用了Win32 API
2. 需要支持C++11标准的编译器
3. 游戏窗口大小固定，不支持调整大小
4. 使用系统默认字体显示中文文本
